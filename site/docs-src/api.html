API reference

The Orbit server is a Hono app on Node. The web, desktop and mobile clients all use the same HTTP API, one Server-Sent Events stream, and two WebSockets: the screen relay and the sign-in terminal. Hermes engines reach the app's tools over MCP.

Conventions

  • Base URL: the server origin, for example http://127.0.0.1:8787. Every route below is under /api unless shown otherwise.
  • Auth: a session cookie (browser, desktop) or Authorization: Bearer <token> (mobile and native clients, from POST /api/auth/sign-in). Everything except /api/auth/*, /api/apps/callback, /api/health and /api/desktop/probe requires a user. Sessions last 30 days.
  • Ownership: every bot, room, routine, skill and file route checks that the resource belongs to the signed-in user, and answers 404 when it does not.
  • Bodies: JSON, validated with zod schemas in apps/server/src/api/schemas.ts. A malformed body is a 400.
  • Errors: { "error": "message" } with a 4xx status. Unexpected failures are a plain-text 500.
  • Types: request and response shapes are shared from packages/contracts (@orbit/contracts).
curl -s http://127.0.0.1:8787/api/health
# {"ok":true,"version":"…","engine":"hermes","uptimeMs":12345}

TOKEN=$(curl -s -X POST http://127.0.0.1:8787/api/auth/sign-in \
  -H 'content-type: application/json' -d '{"email":"you@example.com"}' | jq -r .token)
curl -s -H "Authorization: Bearer $TOKEN" http://127.0.0.1:8787/api/bots

Event stream (SSE)

The first message is always hello with the server's current cursor; resume from that seq, not from your own. A ping is sent after 20 seconds of quiet. Each message's data is one JSON ServerEvent:

helloserverTime, seqConnected; resume cursor.
rowsbotId, generation, rows[]New or revised transcript rows (streaming rewrites rows in place).
clearedbotId, generationConversation reset; drop rows from older generations.

Core types

From packages/contracts/src/index.ts.

Bot

interface Bot {
  id: string; name: string; label: string; description: string; instructions: string;
  avatarShape: AvatarShape; avatarColor: AvatarColor;
  mode: 'personal' | 'teammate'; isPrimary: boolean; kind?: 'agent' | 'room';
  pinned: boolean; effort: 'low' | 'medium' | 'high' | 'xhigh';
  voice: string; voiceSpeed: number; voiceLanguage: string;
  voiceProvider: 'cloud' | 'local' | 'audiocpp'; voiceModel: string;
  audiocppVoice?: string; avatarEnabled?: boolean; hasPortrait?: boolean;  // GPU voice
  model: string | null; provider: string | null;   // null = the engine's default
  generation: number; unread: number; lastPreview: string | null;
  lastActivityAt: number; createdAt: number;
}

Row

interface Row {
  botId: string; generation: number;
  seq: number;          // order in the transcript
  updatedSeq: number;   // per-bot revision counter; rows are rewritten while streaming
  kind: 'message' | 'tool-call' | 'card' | 'event' | 'notice';
  body: MessageBody | ToolCallBody | CardBody | EventBody | NoticeBody;
  createdAt: number;
}

Cards

type CardBody =
  | { card: 'approval'; approvalId; title; detail; tool; args;
      status: 'pending' | 'allowed' | 'always' | 'denied' | 'expired' }
  | { card: 'question'; question; options: string[];
      status: 'pending' | 'answered' | 'dismissed'; answer? }
  | { card: 'connect'; toolkit; toolkitName; reason;
      status: 'pending' | 'connected' | 'skipped' }
  | { card: 'draft'; channel: 'email' | 'slack' | 'message'; to; subject?; text; approvalId;
      status: 'pending' | 'sent' | 'discarded' };

LiveState

interface LiveState {
  botId: string; isRunning: boolean; startedAt: number | null;
  activity: { kind: ActivityKind; detail?: string; since: number } | null;
  awaiting: { reason: string; since: number } | null;
  caption?: string | null;   // a short line from the model's live reasoning
  steps?: number;            // tool calls so far this turn
}
type ActivityKind = 'thinking' | 'working' | 'searching_web' | 'reading_web' | 'browsing_web'
  | 'on_its_computer' | 'running_commands' | 'waiting_on_command' | 'messaging_named'
  | 'connecting_service' | 'waiting_for_you' | 'drafting_file' | 'remembering';
